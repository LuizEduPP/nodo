# Security

This repository is in test. Treat findings as real anyway.

Do not open a public issue for a vulnerability. Use [private vulnerability reporting](https://github.com/LuizEduPP/nodo/security/advisories/new) on this repository.

Include what you found, how to reproduce it, and which files or ports are involved. Port 9400, the store under `XDG_DATA_HOME/nodo`, and anything that looks like a key leak are in scope.

[Luiz Eduardo](https://github.com/LuizEduPP) triages reports. Reporters get credit unless they ask not to.
